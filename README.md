# Asset Utilization Forecasting

Machine learning and time-series forecasting framework for projecting future utilization of heavy equipment and vehicle fleets.

## Objectives

- Forecast operating hours
- Forecast kilometers traveled
- Estimate annual utilization
- Support maintenance and fleet planning

## Models

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor
- Neural Networks (MLP)
- XGBoost
- CatBoost

## Time Series Features

- Lag variables
- Rolling means
- Rolling standard deviations
- Calendar features
- Equipment age
- Accumulated meter readings
